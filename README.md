# Farbaek

From idea to verified software, with control at every step.

Farbaek is in development. Accounts and payments are not open yet. See `docs/architecture/current-state.md` for exactly what works today.

## Run it

Requires Node.js 24 and pnpm 12.

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Check it

```bash
pnpm check
pnpm build
```
