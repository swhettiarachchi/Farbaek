# Farbaek skills inventory

Written on 2026-11-22. This is a read of every Claude skill installed on the Windows PC that Farbaek is built on. 113 `SKILL.md` files are installed in the four places skills live (111 distinct names, because frontend-design is installed three times). 41 were read in full: the 33 named skills that exist as files, audit-as-prod-readiness, and seven short ones whose whole file is under 90 lines. The other 72 were read to at least their first 60 lines. Ten of the longest named files and the 79 other skills were read by helper agents working from the same brief, and every quotation in this file was then read or searched for in the skill file itself. Only `SKILL.md` files were read: the reference files, scripts and assets beside them were not opened, and nothing was run.

What could not be read, and what was left out on purpose:

- **claude-api** has no file on this PC. It is built into Claude Code, like dataviz, code-review, simplify, security-review, run, loop, schedule and the artifact skills. None of those has a `SKILL.md` to read, so none is counted.
- **Two catalogues are on disk but not installed**, so they were counted and not read: 57 `SKILL.md` files in `C:\Users\INTEL\.claude\plugins\marketplaces\claude-plugins-official`, and 533 in a leftover clone of the ECC repository at `C:\Users\INTEL\.claude\plugins\marketplaces\temp_git_1791709950658_ipqz2b..clone` (240 distinct names; most of the files are translated copies).
- **The marketplace copies** of the taste-skill and Cloudflare skills are identical to the installed copies and are counted once.
- **web-design-guidelines** fetches its rules from GitHub each time it runs, so its rules are not on disk.
- **Five plugin slash commands** (Cloudflare's build-agent and build-mcp, website-design's design-system, landing-page and review-page) are commands, not skills.
- Every folder could be listed. The first search of the plugins folder stopped at 100 results, so the count was taken again file by file.
- The only `python` on this PC's PATH is the Windows Store alias under `WindowsApps`. It was not run. Everything below treats Python as not installed.

## What's missing

No installed skill covers these kinds of work. Each is a candidate for a custom skill.

- **Durable workflows and automation.** Queues, retries, schedules and resumable agent runs on the self-hosted VPS. The only close skills assume Cloudflare Workers.
- **Multi-provider model routing and evals.** The Claude and OpenAI ladder, fallbacks, held-out test sets, and cost and quality regressions. claude-api covers Claude only and has no file here.
- **Unit economics and pricing models.** Token cost to plan allowance, margins, the cost of a trial and price tests.
- **Android and iOS assistant integrations.** App Intents, Siri and Shortcuts, Android App Actions, widgets and share sheets. The mobile skills cover screens only.
- **Threat modelling.** Trust boundaries, abuse cases, prompt injection and the computer-task policy. ecc-security-review is a code checklist, not a model of threats.
- **Dark mode and theme engineering.** Token pairs, contrast tests for both themes, scoped theme roots, and media and charts in dark. farbaek-ui has no dark rules yet.
- **A film pipeline that runs on this PC.** Node-only rendering with Geist, the real logo and labelled sample data. Every installed film skill needs Python.
- **Native app engineering and store releases.** SwiftUI, Android and Electron code, signing, and App Store, Play and Microsoft Store submissions. Only screen design is covered.
- **Postgres and migration practice.** Hash-verified migrations with read-backs, row level security and `app_*` function design, backups, and PostGIS, which the survey skill says no reference teaches.
- **Payments and billing operations.** Dodo payments, entitlements, refunds and failed renewals.
- **Web research quality for Chat.** Search planning, ranking, citation checks and running SearXNG. deep-research guides Claude's own research, not the product's.
- **Languages in the interface.** Detection, Sinhala and Tamil type in screens, and right-to-left layouts. sinhala-video-type covers video text only.
- **Running production.** Logs, health checks, deploy read-backs and rollback on the VPS. audit-as-prod-readiness reviews plans, not live systems.
- **Privacy and store declarations.** Data retention, the privacy policy and the stores' privacy forms.
